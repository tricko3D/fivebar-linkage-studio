Gear ratio is motor revolutions per output revolution (3:1 = three motor turns per output turn). Finite-travel servos also lose output angle: (motor travel − 2 × motor end margin) / gear ratio. RPM is an assumed speed, not a torque-speed curve. The path animation checks estimated motor RPM and torque, but not physical collisions.

Calibration needed: The 0.3 N drag and 0.015 N·m joint friction are unmeasured defaults, not calculated from bearings. The motor presets use illustrative running torque. Do not lower these inputs merely to make the map green. XY load uses worst-case planar force direction and an approximate link-mass allowance; it does not model rotor inertia, motor speed–torque curves or all link dynamics.

Structural model approximates the four links as two parallel idealized cantilever chains. It is not FEA and does not include pivot play, tool overhang, Z guide flex, buckling, print defects or motor speed curves.

How to read the model

P is where the two distal links meet. G is the gripper tip. With a tool extension G moves beyond P along a selected distal link, so it changes the inverse kinematics, not just the drawing.
The mechanical estimates are simplified screening calculations, not FEA or a verified safe working load. Check pivot clearances, bearing stiffness, Z-axis overhang, print orientation, impacts and the motor torque-speed curves experimentally. The Z actuator is represented only by its mass.
